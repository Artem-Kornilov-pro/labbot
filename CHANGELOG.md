# История изменений

## v1.0.0 — 2026-11-05

Первый релиз бота.

### Лабораторные работы
- **Лаба 2** «Алгоритмы с досрочным выходом из цикла. Алгоритмы обработки целых чисел»: две программы (17 и 10 задач).
- **Лаба 3** «Использование функций»: три программы — общая часть формулы как функция (10 задач), min/max по
  матрице (9), повторяющиеся элементы массива через указатель (7).
- **Лаба 4** «Обработка символьных строк»: одна программа из трёх подпрограмм — выделение подстрок (12 вариантов),
  поиск подстроки (10), преобразование строки (11); строки в UTF-8, в Windows консоль переключается в UTF-8.
- **Лаба 5** «Файлы»: двоичный файл чисел (12 задач) и построчная обработка текстового файла (9 задач);
  собирается в Visual Studio.
- Отчёт `.docx` по методичке для каждой лабы: титульный лист, содержание, постановка, метод (формулы Word),
  внешняя спецификация (фигуры Word), псевдокод, листинг, тесты и распечатки; открывается в Word без
  «режима ограниченной функциональности».

### Бот
- Лимит — 10 лаб на пользователя (`LAB_LIMIT`), учёт выданных лаб в SQLite; при ошибке генерации лимит не тратится.
- Администраторы по Telegram id (`ADMIN_IDS`) и username (`ADMIN_USERNAMES`, по умолчанию ArtemigKot и ryplesh):
  без лимита.
- Команда `/stats` для администраторов — Excel-таблица со сводкой, пользователями и всеми выдачами.
- Чёрный список по username (`BLOCKED_USERNAMES`).

### Проверки
- Каждая программа собирается `gcc -Wall -Wextra -Werror` и печатает то же, что эмулятор, по которому бот строит
  таблицы тестов; все 1320 сочетаний подпрограмм лабы 4; фаззинг случайными вводами.
- Отчёты проверены в LibreOffice (ничего не выходит за поля) и Word.
